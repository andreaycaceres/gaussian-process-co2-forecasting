## About This Repository

This repository documents my work with Gaussian Processes as part of
STAT 5720. I completed a course-provided notebook by implementing the
missing code sections and working through concepts including covariance
kernels, Gaussian Process priors and posteriors, regression, and noisy
observations.

The course notebook was adapted heavily from a Gaussian Process tutorial
by Peter Roelants. The underlying lesson structure, methodology, and
starter code are not my original work.
